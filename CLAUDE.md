## Gotchas

Facts that cost earlier sessions time. Read the note when your work enters its area.

- `docs/notes/pipecat.md`: before you change the pipeline, a Flows node or tool, turn handling, tracing or the Pipecat version.
- `docs/notes/hapi-fhir.md`: before you write or change a FHIR call, a seed script or the HAPI container.
- `docs/notes/testing.md`: before you write or run a test, or call a paid API. The README's Run the tests section has the commands.
- `docs/notes/llm-configs.md`: before you add or change an LLM config or the model behind one.
